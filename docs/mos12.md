# TLOU - Live Wallpaper / MOS 12

Нативные живые обои для MOS 12, KDE Plasma 5.27 и Qt 5.15.

```sh
sudo dnf install ./tlou-wallpaper-1.0.0-1.mos12.noarch.rpm
```

Открыть **Настройки рабочего стола → Тип обоев → TLOU - Live Wallpaper**.
Пакет устанавливается для всех пользователей в
`/usr/share/plasma/wallpapers/org.tlou.stillalive` и не переключает фон автоматически.

Доступны все эффекты и настройки версии MOS 13: время суток по часам или вручную,
ветер, свет, пыль, ночные светлячки, качество, FPS, пауза и автопауза,
когда экран закрыт развёрнутым или полноэкранным окном текущего рабочего стола.
Настройки сохраняются средствами Plasma.

Сцена работает внутри Plasma средствами Qt Quick и OpenGL. Браузер, Node.js,
сервер и внешний проигрыватель на рабочем компьютере не нужны.
При программном backend Qt Quick отображается статичное изображение.
OpenGL через llvmpipe может выполнять анимацию на CPU; для плавной работы
предпочтительно аппаратное ускорение. Для меньшей нагрузки выбрать eco и 15-30 FPS.

Обновление: установить новый RPM, затем повторно выбрать обои или войти в сеанс заново.
Удаление: `sudo dnf remove tlou-wallpaper`.
Пользовательская копия с тем же идентификатором может перекрывать системную;
удалить её через `kpackagetool5 --type Plasma/Wallpaper --remove org.tlou.stillalive`.

Сборка: `npm run build`, затем `sh build/rpm.sh mos12` на Linux с rpmbuild.
`sh build/rpm.sh all` собирает оба RPM. На Windows использовать
`build/build.ps1 -Target all` (WSL и контейнер с rpmbuild).
Qt 6 Shader Tools нужны на машине полной сборки для версии MOS 13, но не при установке MOS 12.
