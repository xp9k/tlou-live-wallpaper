TLOU - Live Wallpaper / Windows

Установка в Lively Wallpaper

1. Установите и запустите Lively Wallpaper:
   https://www.rocksdanister.com/lively/
2. Перетащите ZIP-архив с этой темой в окно Lively. LivelyInfo.json находится
   в корне архива, поэтому тема импортируется вместе с названием и превью.
3. Выберите TLOU - Live Wallpaper в библиотеке.
4. Нажмите правой кнопкой по теме и выберите «Настроить» (Customise).
   Здесь доступны ветер, яркость, пыль, качество, FPS, пауза,
   время суток и количество светлячков. Lively сохраняет выбранные значения.
   Ручное время применяется в режиме «Вручную» и задается в минутах от
   полуночи: например, 780 означает 13:00, 1290 означает 21:30.

Если тема уже была установлена из старого ZIP без настроек, импортируйте
новый ZIP и выберите новую копию темы в библиотеке.

Если импорт ZIP недоступен: распакуйте архив целиком в постоянную папку,
добавьте через Lively файл index.html и выберите обои в библиотеке.
Не перемещайте и не удаляйте папку, пока Lively использует её файлы.

Предпросмотр: распакуйте архив и откройте index.html в браузере.
Для установки анимации на рабочий стол используется Lively.
Node.js и локальный сервер для готовой темы не нужны.

Параметры URL для ручной настройки:
  ?quality=eco&fps=30 - экономичный режим;
  ?wind=0.5&dust=1&light=1 - сила ветра, количество пыли и яркость;
  ?hour=21.5 - время суток вручную (0-24), без параметра освещение
  следует часам компьютера;
  ?fireflies=40 - количество светлячков ночью (0-64, 0 - без светлячков).
По умолчанию: ultra, 60 FPS.

Пробел - пауза, F - полноэкранный просмотр, двойной щелчок - полный экран.
Эти клавиши работают, когда фокус находится на окне предпросмотра.
